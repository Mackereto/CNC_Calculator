เครื่องคำนวณรอบสปินเดิล (S) และอัตราป้อน (F)

เลือกวัสดุ ชนิดดอก และขนาดดอก ระบบจะเติม Vc และ fz ที่แนะนำตามแคตตาล็อก OSG (เหล็ก) หรือ Harvey Tool (ไนลอน/พลาสติก) ให้ แก้เองได้ และจะเตือนเมื่อค่าสูงหรือต่ำเกินไป

ค่าที่กรอก

ลดเฉพาะ Vc ไม่ลด fz เป็นหลักปฏิบัติของผู้จัดทำ ไม่ได้มาจากแคตตาล็อก
ไม่ปรับค่าแนะนำ ใช้เตือนเมื่อไม่เหมาะกับช่วงความแข็ง
ใช้ตรวจกับเงื่อนไขแคตตาล็อกและนับจำนวนชั้น
ขีดจำกัดเครื่องจักร

เวลาเดินมีดเชิงทฤษฎี

ค่าแนะนำดอกปลายเรียบและรัศมีมุมมาจากแคตตาล็อก OSG A Brand AE-MS-H / AE-CR-MS-H (Side Milling, หน้า 1348) ดอกบอลมาจาก AE-BM-H (หน้า 1467 งานหยาบ, 1468 งานเก็บผิว ขนาด 2–12 mm ประมาณค่าระหว่างขนาด) ดอกบอลและรัศมีมุมคิดรอบจาก Deff ให้ได้ Vc ที่จุดสัมผัสเท่าตาราง และปรับ fz ให้ความหนาเศษเท่าเงื่อนไขตาราง (สูงสุด 2 เท่า) · Deff บอล = 2√(ap(D−ap)), Deff รัศมีมุม = D − 2r + 2√(2r·ap − ap²) เมื่อ ap < r · scallop = R − √(R² − (ae/2)²) · ดอกปลายเรียบ: Vc ค่ากลางของช่วง และ fz = 1.0% ของ D (ไม่เกิน 55 HRC), 0.7% (55–62 HRC), 0.6% (62–66 HRC) ที่ ap = 1.5D (62–66 HRC ใช้ 1D) และ ae ตามตาราง · ปรับ fz ตาม ae จริงด้วย k = 2√(r − r²) เมื่อ r = ae/D < 0.5 (r ≥ 0.5 ใช้ k = 1) และ fz ตั้ง = fz แนะนำ × k(ae ตาราง) / k(ae จริง) · n = 1000·Vc / (π·D) · Vf = fz × z × n · N = max(1, ⌈(B−D)/(ae·D)⌉ + 1) · t = 60·A·N / Vf · จำนวนชั้น = ⌈H / ap⌉ · เวลารวม = t × จำนวนชั้น
ไนลอน/พลาสติก: ค่าแนะนำมาจากตาราง Harvey Tool (ดอกพลาสติก 3 ฟัน ไม่เคลือบ) ไม่ใช่ตารางเหล็ก ระยะยื่นและเกณฑ์เตือนใช้ชุดเดียวกัน แต่ไม่มีค่าอ้างอิงดอกบอล/รัศมีมุมสำหรับไนลอน
เกณฑ์เตือน: Vc นอกช่วงแนะนำ = เตือน, เกินขอบบน 15% = อันตราย · ความหนาเศษเกินค่าแนะนำ 20% = เตือน, 50% = อันตราย · บางกว่าค่าแนะนำ 40% = เตือน, 65% = อันตราย (เสี่ยงเสียดสีแทนการตัด) · ระยะยื่นเกิน 4D ลดค่าแนะนำ (≤5D: Vc 90% fz 80%, ≤6D: 80%/65%, ≤8D: 70%/50%, เกิน 8D: 60%/40%) ตัวคูณนี้เป็นหลักปฏิบัติทั่วไป ไม่ได้มาจากแคตตาล็อก (OSG ระบุเพียงให้ลด speed, feed และความลึกเมื่อยื่นเกิน 4D) · ap ลึกกว่าเงื่อนไขแคตตาล็อก = เตือน, เกิน 50% = อันตราย (ap ตื้นไม่ลดค่าแนะนำ) · ผลทั้งหมดเป็นค่าเริ่มต้น ต้องทดลองยืนยันก่อนใช้เป็นมาตรฐาน และดอกยี่ห้ออื่น เช่น NS ควรตรวจกับ catalog ของผู้ผลิตนั้น · ค่าเริ่มต้นของ Vc คูณด้วยตัวคูณความปลอดภัย (ค่าตั้งต้น 85%) ซึ่งเป็นหลักปฏิบัติของผู้จัดทำ ไม่ได้มาจากแคตตาล็อก และช่องสารเคลือบเป็นข้อมูลประกอบ ไม่ปรับตัวเลข

ตารางอ้างอิงและที่มาของค่าแนะนำ

ค่าแนะนำทั้งหมดในเครื่องคำนวณมาจากแคตตาล็อกเทคนิคของ OSG (End Mill Technical) สำหรับดอกคาร์ไบด์เคลือบ DUROREY ที่ออกแบบมาสำหรับเหล็กชุบแข็ง ตารางด้านล่างแปลงหน่วยจากต้นฉบับ (in/min × 25.4 = mm/min, SFM × 0.3048 = m/min) แล้วคำนวณ Vc = π·D·n/1000 และ fz = F/(z·n) จากรอบและฟีดในตาราง รอบในตารางเป็นค่าของผู้ผลิต บางขนาดเกินเพดานรอบของเครื่องเรา (19,200 rpm) เครื่องคำนวณจะจำกัดให้เอง
